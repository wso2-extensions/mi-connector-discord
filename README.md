# Discord Connector for WSO2 MI

The Discord connector offers APIs to connect and interact with the Discord REST API, enabling the integration of messaging, user management, and community engagement features into applications

### Compatibility

| Connector Version | Supported WSO2 MI Version |
|-------------------|---------------------------|
| 0.1.0             | MI 4.6.0     |


## Documentation

Please refer to the [Discord Connector Overview](https://mi.docs.wso2.com/en/latest/reference/connectors/) documentation.

### Building From the Source

Follow the steps given below to build the connector from the source code:

1. Get a clone or download the source from [Github](https://github.com/wso2-extensions/mi-connector-discord/).
2. Run the following Maven command from the `mi-connector-discord` directory: `mvn clean install`.
3. The ZIP with the Discord connector is created in the `mi-connector-discord/target` directory.
